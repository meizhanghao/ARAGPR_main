# 原型辅助命名：提示词与记录

[English](README.md)

这里提供“CLIP 候选排序＋GPT-4o 视觉决选”的提示词及空白记录模板。
它们不是已经运行的结果，也没有补造模型版本、日期或输出。
现有 CLIP 初跑工具位于 `tools/naming/run_shape_naming_pilot.py`，
从仓库根目录执行：

```bash
python -m tools.naming.run_shape_naming_pilot --help
```

该工具只执行本地 CLIP 排序，不调用 GPT-4o；其中的示例参考路径和候选词
需要按实际原型修改。完整命名可自动完成，人工仅按需要事后检查。

## 实际操作

1. 固定训练原型及其代表区域，准备标出区域的原图、RGB 局部图、轮廓图。
2. 准备候选词表并保存出处。数据集原有标注和作者自拟的形状词分别注明。
3. RGB 局部送入 CLIP 图像编码器，候选文本送入文本编码器；嵌入 L2 归一化后，
   按余弦相似度排序，保留前三名。记录模型、文本模板和图像预处理。
4. 使用 [英文提示词](prompts/vlm_selection.txt)，填入原型 ID、前三候选，
   并同时提供上述三张图。让 GPT-4o 选取、必要时精简或无法判断时弃权。
5. 保存实际提示词、原始返回和最终名称，名称与 P 编号并列展示。

名称帮助读者理解训练参考内容，不参与训练、预测或贡献计算。
不向命名步骤提供贡献正负或预测结果来诱导名称，也不由一个参考区域推断
全簇都属于同一部件。医学图像仅命名可见形态，不推断良恶性或诊断。

## 要留存／提交的文档类型

模板集中在 [templates/](templates/)，建议每次复制到新的
`outputs/prototype_naming/运行编号/` 下填写。

| 文件 | 用途 |
|---|---|
| `run_metadata.json` | GPT-4o 实际标识／使用日期、服务、参数及 CLIP 配置 |
| `reference_manifest.csv` | 原型、训练图像／局部／轮廓来源、选择规则及哈希 |
| `candidate_terms.csv` | 完整候选词表及各词来源 |
| `clip_rankings.csv` | CLIP 分数和排序，至少保留前三，优先保留完整排序 |
| `prompts/Pxxxx.txt` | 实际提交的完整提示词 |
| `responses/Pxxxx.json` | API 原始返回，或所用界面的逐字输出导出 |
| `parsed/Pxxxx.json` | 解析后的名称、选中候选和简短依据 |
| `naming_summary.csv` | 最终名称及与上述记录的对应关系 |

如果界面只显示 GPT-4o，记录服务名称和实际使用日期即可；未提供的底层模型
快照或参数留空。模板不需要论文格式，也不用 Word；TXT、CSV、JSON 更便于核查。
将提示词、词表、排序、名称和运行信息随代码或关联归档公开；原始图像可以保留
在外部数据目录，通过图像键和哈希追溯。不要把空白模板作为已完成实验记录。
