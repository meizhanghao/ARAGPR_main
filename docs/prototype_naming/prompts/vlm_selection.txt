TASK
Choose the candidate that best describes the marked region's visible content and outline. The CLIP ranking is a proposal, not a probability or a requirement to choose rank 1. If useful, refine a candidate into a short noun phrase combining an identifiable part/object and observable shape. Use approximately 2-6 English words. If none is supported, abstain; do not force a plausible-sounding name.

RULES
- Use the full image to locate the region, the crop to identify its content, and the contour to check the shape description. Do not assign nearby content to the marked region.
- For bird images, identify a visible part only when supported; avoid a species-specific claim based on the dataset or image class.
- For skin images, describe visible region morphology, not malignancy, diagnosis or clinical meaning.
- For scene images, name an object only when identifiable; otherwise use a simple outline description.
- Do not use color/texture to invent an unsupported geometric property.
- A representative reference does not establish semantic purity of its cluster. If supplied members conflict, record that limitation rather than treating them as identical.
- The label helps a reader inspect training-reference content. It does not participate in training, prediction or contribution calculation, and does not establish localization in a test image.
- Return one JSON object only. Use null for an unavailable name or candidate rank. Do not append a prototype ID to the name; it will be displayed separately.
